# ZEKE Roadmap

**Status:** Canonical current roadmap for v0.45.1 build 2026.08.23.4. Completed work is recorded in `RELEASE_NOTES.md` and `DEVELOPMENT_MEMORY/ITERATION_HISTORY.md`.

## Current acceptance
- Complete package-local governance, syntax, regression, dependency, PT-media, extraction, and ZIP verification.
- Owner hands-on validation of mobile and desktop Fitness flows: browse → plan → inspect/modify → start → coach/adapt → finish → review.
- Verify real Google Drive/Calendar readback and connected-AI workout generation in deployment.
- Validate first real PDF/screenshot/DEXA ingestion review before any bulk reliance.

## Near-term
- Refine Fitness hierarchy and workout coaching from hands-on use without introducing artificial browse/workout modes.
- Expand verified exercise/PT media and evidence metadata.
- Deepen training-load/fatigue intelligence while preserving transparent progression/regression criteria.
- Implement any future Calendar write action only with the Constitution's staged/per-event sensitive consent.

## Later
- Provider adapters beyond Google Drive.
- Encrypted provider-backed AI credential vault.
- Apple Health and other explicitly authorized, user-controlled integrations.
- Broader personal-management modules without weakening the health-first canonical longitudinal model.
