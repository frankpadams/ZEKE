# Deploy ZEKE v0.40.0

**Build:** 2026.08.03.1

1. Back up the current GitHub repository.
2. Replace the repository contents with this package as one consistent set.
3. Commit and wait for GitHub Pages deployment to complete.
4. Open ZEKE and confirm the startup screen shows v0.40.0 / 2026.08.03.1.
5. Hard refresh once to activate the new service worker.
6. Connect Google Drive and review Data Integrity candidates before approving any repair.

Git compares file content and paths, not modification dates. This package nevertheless uses accurate current timestamps for changed/new files and includes hashes so deployment correctness does not depend on timestamps.
